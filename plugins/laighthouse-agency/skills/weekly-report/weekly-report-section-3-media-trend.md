## MCP 호출

`get_ad_performance` ×1 — `time_grain:"day"`, `group_by:["media"]`, `start_date` = E-34, `end_date` = E, `metrics`·`filters` 생략.

## 빌더 입력 (`assets/prepare.py`가 채운다 — 저장 훅이 없을 때만 직접 만든다)

```json
"s3": {"json_files": ["<응답 파일>"]}
```

## 빌더가 하는 일

- E부터 거꾸로 7일씩 5주로 묶는다(라벨 예: `8/16~22`, `8/30~9/5`). 매체마다 라인 1개, 지표 드롭다운 = 서빙 지표.
- 주 값: 광고비·노출·클릭·조회수는 합, CTR·CPM·CPV는 그 주 합으로 다시 계산. 다시 계산할 수 없는 비율 지표(VTR 등)는
  값이 없어 **드롭다운에서 조용히 빠진다**.
- 표의 이번주·전주 매체별 합과 이 응답의 같은 주 합을 대조 검증한다(어긋나면 빌더가 멈춘다).
