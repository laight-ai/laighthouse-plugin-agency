# section-2: Weekly Summary

신규 MCP 호출 없음. **`assets/prepare.py` 출력의 `digest`**(이번주·전주 값과 변화, 월 누적 소진율·기간 진행률)만 근거로 실행 모델이
직접 쓴다 — 응답 파일을 열어 보지 않는다. 근거 수치가 없는 문장(원인 추정, 변경 이력, 예측)은 쓰지 않는다.

## 빌더 입력

```json
"s2": {"groups": [
  {"title": "소진",
   "lead": "이번주 광고비는 <strong>₩57,905,117</strong>로 전주 대비 +4%이며, 월 예산의 59.0%를 소진했습니다(기간 진행률 63.3%).",
   "media": [
     {"name": "Google", "desc": "이번주 광고비 ₩37,144,838로 전주 대비 +0%이며, 4개 상품 중 2개 상품의 소진 확인이 필요합니다.",
      "bullets": [{"label": "Masthead", "text": "광고비 ₩14,312,189로 전주 대비 -2%, 안정적으로 소진 중입니다.", "tone": "neutral"},
                  {"label": "VVC", "text": "광고비가 전주 대비 <strong>-32%</strong> 감소했습니다.", "tone": "red"}]}]},
  {"title": "효율", "lead": "전체 CPV는 ₩9.8로 전주 대비 +2%입니다.", "media": [...]}
]}
```

- `media[].name`: digest의 매체 이름 그대로(점 색은 빌더가 매체 색으로 붙인다).
- `bullets[].label`: 상품 이름(응답에 상품 차원이 없으면 digest의 `매체-상품`이 없다 — 그때는 bullets를 비우고 `desc`만 쓴다).
- `tone`: 라벨 색 — `red`(감소·급증 등 점검), `yellow`(주의), `green`(개선), `neutral`(안정).
- 본문은 `<strong>`만 허용, 다른 태그는 글자로 보인다.

## 작성 규칙

1. **[소진]** — `lead`: 이번주 전체 광고비와 전주 대비 %, 월 예산 소진율과 기간 진행률(digest `월누적`; 예산이 없으면 생략).
   매체마다 `desc`(이번주 광고비·전주 대비, 점검이 필요한 상품 수) + 상품마다 불릿 1개(광고비·전주 대비).
   전주 대비 광고비 -15% 이하 감소는 `red`, +25% 이상 증가는 `red`, 그 밖에 ±10% 이상은 `yellow`, 나머지 `neutral`.
2. **[효율]** — `lead`: 전체 CPV(없으면 CPM/CTR)와 전주 대비. 매체마다 `desc`(CPV·CTR과 전주 대비) + 상품마다 불릿 1개
   (CPV 전주 → 이번주, 변화율, CTR과 %p). CPV 10% 이상 상승 `red`, 10% 이상 개선 `green`, 나머지 `neutral`.
- 변화율은 digest `변화` 값을 그대로 쓴다(반올림해 정수 % 표기 가능). 금액은 `₩` + 콤마.
