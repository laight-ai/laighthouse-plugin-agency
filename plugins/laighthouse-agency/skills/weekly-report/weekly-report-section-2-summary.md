# section-2: Weekly Summary

신규 MCP 호출 없음. **`assets/prepare.py` 출력의 `digest`**만 근거로 실행 모델이 직접 쓴다 — 응답 파일을 열어 보지 않는다.
근거 수치가 없는 문장(원인 추정, 변경 이력, 예측)은 쓰지 않는다.

**무엇을 어떻게 쓸지(목적·작성 규칙·예시)는 `guides/weekly-summary.md`를 따른다.** 그 파일은 비개발자가 노션에서 고치는
가이드의 사본이다(README의 "요약 가이드" 절). 이 문서는 근거 데이터와 빌더 입력 형식만 정한다.

## 근거 (`digest`)

- `이번주`·`전주`: 기간 라벨. `월누적`: 월 누적 광고비·월 예산·소진율·기간 진행률·목표.
- `전체`, `매체`: 이번주·전주 값과 `변화`.
- `매체-캠페인`, `매체-캠페인-광고그룹`: 단위마다 **이번주 광고비 상위 + 전주 대비 광고비 변동(절대액) 상위**를 합친 행
  (이름은 `매체 / 캠페인 / …`). 응답에 없는 차원의 단위는 빠진다. `… 생략`은 빠진 행 수다.
- 변화율은 digest `변화` 값을 그대로 쓴다(반올림해 정수 % 표기 가능). 직접 계산하지 않는다.

## 빌더 입력

```json
"s2": {"groups": [
  {"title": "소진",
   "lead": "이번주 광고비는 <strong>₩57,905,117</strong>로 전주 대비 +4%이며, 월 예산의 59.0%를 소진했습니다(기간 진행률 63.3%).",
   "media": [
     {"name": "Google", "desc": "이번주 광고비 ₩37,144,838로 전주 대비 +0%이며, 4개 캠페인 중 1개 캠페인의 소진 확인이 필요합니다.",
      "bullets": [{"label": "Skippable(MF2554)", "text": "광고비 ₩14,312,189로 전주 대비 -2%, 안정적으로 소진 중입니다.", "tone": "neutral"},
                  {"label": "Non-skip(MF2554)", "text": "광고비가 전주 대비 <strong>-32%</strong> 감소했습니다.", "tone": "red"}]}]},
  {"title": "효율", "lead": "전체 CPV는 ₩9.8로 전주 대비 +2%입니다.", "media": [...]}
]}
```

- `media[].name`: digest의 매체 이름 그대로(점 색은 빌더가 매체 색으로 붙인다).
- `bullets[].label`: 캠페인(또는 광고그룹) 이름. 캠페인 차원이 없으면 bullets를 비우고 `desc`만 쓴다.
- `tone`: 라벨 색 — `red`(빨강), `yellow`(노랑), `green`(초록), `neutral`(회색). 가이드의 색 이름을 이 값으로 옮긴다.
- 본문은 `<strong>`만 허용, 다른 태그는 글자로 보인다.
