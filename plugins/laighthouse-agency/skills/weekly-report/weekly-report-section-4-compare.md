## 빌더 입력 (`assets/prepare.py`가 채운다 — 저장 훅이 없을 때만 직접 만든다)

```json
"s4": {"cur": {"json_files": ["<이번주 응답 파일>"]}, "base": {"json_files": ["<전주 응답 파일>"]}}
```

## 화면 (`LHKit.pickTable`)

- **Dimension 메뉴**: 응답에 온 차원만(매체·상품·캠페인·광고그룹·소재 중 있는 것) 체크·순서 변경·초기화. 최소 1개.
  기본 = 상품을 뺀 전부(그러면 1개 이하가 되면 전부). **없는 차원은 메뉴에 나오지 않는다.**
- **지표 메뉴**: 서빙 지표 전부, 처음엔 광고비만 켜져 있고 사용자가 늘린다(광고비는 맨 앞 고정).
- 행 = 고른 차원 조합 단위로 묶은 값, 이번주 광고비 순, 페이지당 10행, 맨 아래 **전체**(검색 시 "검색 결과 합계").
- 열 = 지표마다 [전주, 이번주] + 이번주 아래 전주 대비 증감(% 지표는 %p).
- 검색: 표 오른쪽 위 `[검색 기준 | 차원 ▾ | 검색어]` 한 덩어리 — 고른 차원 중 하나에서 부분 일치(기본 캠페인).
- 값 규칙: 원 행 1개 = 서버 값, 여럿 = 가산 지표 합 + CTR·CPM·CPV 재계산, 그 밖의 비율 지표 `-`.
