# section-3: 월·미디어 필터 + Product · Target · Placement · Weekly · Daily

표 데이터(`data`)로 브라우저가 그린다. 위쪽 필터 바(스크롤해도 붙어 있다)의 **월**(집계 기간이 걸친 달)과 **미디어** 선택이 아래 표 모두에 공통 적용된다.
`필터 초기화` = 전체 월·전체 미디어.

| 표 | 행 계층 | 설정 |
|---|---|---|
| Product | 미디어 → 상품 (기본) | 디멘전 설정 · 지표 설정 |
| Target | 미디어 → 상품 → 광고 그룹 (기본) | 디멘전 설정 · 지표 설정 |
| Placement | 미디어 → 상품(Ad Type) → 노출 위치 | 지표 설정 — 노출 위치 데이터(`place`)가 없으면 '준비 중' 안내 |
| Weekly | 미디어 → 상품 → Week(ISO 주차, `41주차`) | 지표 설정 |
| Daily | 미디어 → 상품 → 일(`2026.10.7`) | 지표 설정 (표 높이 고정, 안에서 스크롤) |

- 디멘전 = 캠페인 · 상품 · 광고 그룹 · 소재 중 응답에 있는 것. 응답에 없는 차원은 메뉴에도 없다(상품이 없으면 Weekly·Daily는 미디어 → 주·일).
- 지표 = 비용 · 노출 · 클릭 · 조회 · CPM · CPC · CTR · CPV · VTR.
- **Placement**: 노출 위치는 ELT 차원(`placement` 등 — 빌더 `PLACE_DIMS`)이다. 표 데이터에 넣으면 행이 크게 늘어서
  `미디어 × 상품 × 노출 위치 × 일`을 따로 받아(`place`) 이 표만 그린다. 차원이 없는 브랜드는 호출하지 않고, 표 자리에
  `노출 위치 데이터 준비 중` 안내를 둔다(섹션·목차는 남는다 — 차원이 생기면 다음 보고서부터 채워진다).
  매체별 일 합과 대조 검증한다(표 데이터와 같은 규칙).
- 묶음마다 `{이름} 요약` 행, 맨 아래 `총합계`. 묶음 이름 옆 `▼`/`▶`로 접고 편다(접으면 요약 행만 남는다).
- **단계 접기**: 제목 줄 `펼침 [미디어][상품][전체]` — 고른 단계까지만 보이고 그 아래는 모두 접힌다(`전체` = 모두 펼침).
  Total/Monthly Summary(`[월][미디어][전체]` — 달을 접으면 `N월 요약`만)·Mix(`Total` 줄이 있는 묶음)도 같다.
- 이름 칸은 자르지 않는다 — 200px를 넘는 이름만 칸 안에서 줄을 바꿔, 기본 영역이 화면 폭 안에 들어오게 한다.
- 오른쪽 목차: 섹션 제목 바로가기 + 지금 보는 섹션 표시 + 맨 위로(좁은 화면은 점만, 마우스를 올리면 펼침).
- 디멘전·지표 설정(선택·순서)은 브라우저에 저장되어 다음에 열어도 유지된다. 메뉴의 `초기화` = 기본값.
- 행 순서: 미디어·상품 등은 집계 기간 광고비 큰 순, 주·일은 날짜 순.
- **많은 행 접기**: 묶음마다 광고비 상위 항목만 먼저 그린다(둘째 단계까지 10개, 그 아래 5개). 나머지는 `외 N개` 한 줄에 그 합계를 보이고
  `더 보기`(+20)·`전체`로 펼친다. 주·일 단계는 자르지 않는다. 요약·총합계 행은 항상 전체 기준이다(Total/Monthly Summary도 같다).
  실적이 전부 0인 행은 빌더가 처음부터 뺀다(합계 영향 없음).

## 엑셀로 가져가기 (모든 표 공통 — Total·Monthly Summary·Mix 포함)

- 각 표 제목 줄 오른쪽 끝의 시트 아이콘(설정 메뉴 옆)을 누르면 **화면에 보이는 그대로**(켠 지표·순서, 접은 상태, 필터)
  표가 클립보드에 담긴다 — 엑셀·구글 시트에 Ctrl+V. 아이콘이 잠깐 체크로 바뀌고 아래에 "N행을 담았어요" 안내가 뜬다.
- 표 위에 마우스를 둔 채 글자를 고르지 않고 **Ctrl+C**(⌘C)를 눌러도 그 표 전체가 복사된다.
- 화면에서 비워 둔 묶음 칸(같은 미디어·상품)은 **채워서** 보낸다 — 붙여넣은 뒤 바로 필터·피벗을 걸 수 있다.
  병합 칸은 빈 칸으로 펼쳐 열이 어긋나지 않는다. 요약·총합계 행과 캠페인명(입력값)도 그대로 들어간다.
