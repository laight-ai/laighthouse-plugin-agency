# section-1: Daily Comment · Weekly Comment

신규 MCP 호출 없음. **빌더가 표 데이터(일 × FINE_DIMS)로 문장을 만든다** — 모델은 문장을 쓰거나 고치지 않는다.
판정 단위(이하 "라인") = 매체 × 상품 × 광고그룹(응답에 있는 것만, 둘 다 없으면 캠페인).

## Daily Comment (E vs E-1)

- 제목 옆: `{E} vs {E-1} · 집행 중 광고그룹 N개 · 급감 기준 −20%`
- 첫 문장: E의 광고비·노출·클릭과 전일 대비 %.
- 매체마다 불릿(광고비 큰 순):
  - 급감 라인이 있으면 `전일 대비 급감한 광고그룹이 N개 확인되었습니다.` + 라인별 하위 불릿
    - 전일 광고비가 있고 E 광고비가 0 → `전일 대비 광고비가 집행되지 않았습니다. 캠페인 상태 확인이 필요합니다.`
    - 광고비·노출·클릭 중 −20% 이하 → `광고비 a → b(−x%), … 감소하였습니다. 입찰 및 소재 노출 상태 점검이 필요합니다.`
    - 라인 이름 = 상품, 같은 매체에서 한 상품이 광고그룹 여럿이면 `상품(광고그룹)`.
    - 매체마다 광고비가 많이 줄어든 순으로 **상위 5개**만 적고, 나머지는 `외 N개 광고그룹` 한 줄로 묶는다
      (개수 문장은 전체 개수). 실데이터는 광고그룹이 수백 개라 하루 몇천 원짜리 변동까지 다 적으면 읽을 수 없다.
  - E에 집행이 없으면 `특이사항 없음 (전일 대비 집행 중단)` 또는 `특이사항 없음 ({마지막 집행일} 집행 종료)`.
  - 그 밖에는 `특이사항 없음 (광고비 ±x%, 노출 ±y%, 클릭 ±z%)`.
- 맺음: 급감이 있으면 `급감 광고그룹 외에는 …정상 운영 중입니다.`, 없으면 `전 매체 모두 … 급감한 광고그룹은 없으며 …`.

## Weekly Comment (ISO 주: E가 속한 주 vs 직전 주)

- 제목 옆: `41주차(10.5–10.7, 3일) vs 40주차(9.28–10.4, 7일) · 일평균/단가 기준`
- **[소진]**: 이번 주 일평균 광고비 vs 직전 주(이번 주에 집행 중인 라인만) — ±5% 미만이면 "유사하게 안정적",
  아니면 증가/감소 %. 당월 예산(전체 범위, 없으면 매체 예산 합)이 있으면 소진율 vs 진행율(경과일/월 일수):
  차이 3%p 미만 "맞춰 운영", 앞서면 "일 예산 조정 검토", 뒤처지면 "소진 속도 점검". 직전 주에만 집행한 매체는 집행 종료일과 함께 적는다.
- **[효율]**: 전체 한 줄(CPM·CPV 변화 기준) + 매체마다 요약(CPM·CPV·VTR과 직전 주 대비) + 상품마다 한 줄
  (조회 지표가 없는 브랜드는 매체 요약에 CPV·VTR 대신 CTR. 상품 줄은 광고비 상위 5개 + `외 N개`)
  (CPM·CPV ±5%, VTR ±3%p, CTR ±15% 중 변화가 큰 2개, 없으면 "직전 주와 유사한 효율").
- 분모가 0인 비교(이번 주나 직전 주 노출 0 등)는 문장에서 뺀다. 집행이 끝난 매체는 마지막 집행일을 적는다.
- 단가·비율은 합친 광고비·노출·클릭·조회수로 계산한다(CPM = 광고비/노출×1000, CPV = 광고비/조회수, VTR = 조회수/노출, CTR = 클릭/노출).
