# 전체 구성과 시작하기

## 화면 구성

- **왼쪽 아이콘 줄**: 맨 위 로고를 누르면 홈으로 간다. 그 아래에 **데이터 관리 · 성과 분석 · 소재 운영 · 조직 관리**가 있다.
  - 권한이나 계약 범위 때문에 볼 수 있는 메뉴가 하나도 없는 영역은 아이콘이 나오지 않는다.
  - 승인 권한이 있으면 조직 관리 아이콘에 승인 대기 건수가 붙는다.
  - 게스트(외부 사용자)에게는 조직 관리가 없다.
- **사이드 메뉴**: 고른 영역의 메뉴가 나온다. **준비 중**이 붙은 메뉴는 아직 쓸 수 없다.
- **오른쪽 위**
  - 언어: 한국어 · English · 日本語
  - 이름 메뉴: **내 계정 · 도움말 · 회사 정보 · 로그아웃**. 도움말에서 문의처(support@laight.ai)를 볼 수 있다.

## 메뉴 한눈에 보기

메뉴는 계약한 서비스와 내 역할에 따라 보이는 것이 다르다.

| 영역 | 메뉴 |
|---|---|
| 데이터 관리 | 매체 API 연동 · 데이터 수동 업로드 · 데이터 수집 현황 · 원본 데이터 다운로드 |
| 성과 분석 | 보고서 조회 · 보고서 생성 · 라이브 대시보드 · 프로모션 캘린더 · 목표 및 수수료 설정 · MCP 서비스 · 메신저 알림 · 월간 미디어믹스 · AI 프레젠테이션(준비 중) |
| 소재 운영 | 소재 시안 제작 · 광고 라이브러리 · 광고 분석 · 마이페이지 |
| 조직 관리 | 멤버 · 승인함 · 변경 이력 · 광고주 관리 |

영역 아이콘을 누르면 그 영역의 첫 메뉴가 열린다. 데이터 관리는 매체 API 연동, 성과 분석은 보고서 조회, 소재 운영은 소재 시안 제작, 조직 관리는 멤버다. 그 메뉴를 볼 수 없으면 볼 수 있는 첫 메뉴가 열린다.

## 브랜드 전환

데이터 관리 · 성과 분석 · 소재 운영 화면은 지금 고른 브랜드의 내용을 보여 준다.

1. 사이드바 맨 위 브랜드 선택을 누른다. 광고주 › 브랜드 같은 조직 트리가 열린다.
2. **브랜드 · 상위 조직 단위 검색** 칸에 이름을 넣어 찾는다.
3. 바꿀 브랜드를 누른다.

- **데이터 연결 없음**이 붙은 단위는 고를 수 없다. 데이터가 연결된 단위만 브랜드로 고를 수 있다.
- 브랜드를 바꿔도 보던 메뉴에 그대로 있다. 다만 보고서 상세·편집·생성 화면에서 바꾸면 새 브랜드의 첫 화면으로, Meta 페이지 화면에서 바꾸면 매체 API 연동으로 간다.
- 광고주 관리 권한이 있으면 목록 아래 **광고주 관리에서 편집 →**으로 조직 구조를 고치러 갈 수 있다.
- **연결된 브랜드 없음**이 보이면, 열람 권한을 받은 브랜드가 없거나 데이터가 연결된 브랜드가 아직 없는 것이다. 조직 관리자에게 브랜드 권한을 요청한다.

## 가입과 로그인 — /login, /signup

- **로그인**: **Google로 계속하기**, **Microsoft로 계속하기**, 또는 이메일·비밀번호로 로그인한다.
- **가입**: Google·Microsoft 계정으로 가입하거나, 이메일 · 비밀번호(8자 이상, 숫자·영문자·특수문자 포함) · 성함을 넣고 약관에 동의한다. 이메일로 가입하면 인증 메일이 오고, 메일의 **이메일 인증하기**를 눌러야 가입이 끝난다. 링크가 만료됐으면 **인증 메일 다시 받기**를 누른다.
- **비밀번호를 잊었을 때**: 로그인 화면 **비밀번호 찾기 ›** → **재설정 링크 받기** → 메일의 링크에서 새 비밀번호를 정한다.
  - Google·Microsoft로 가입한 계정은 비밀번호가 없어 재설정할 수 없다. 가입한 계정으로 로그인한다.

## 처음 로그인했을 때

- **한 계정은 한 조직에만 속한다.** 초대를 수락하면 그 조직에 소속되고 다른 조직에는 참여할 수 없다.
- **소속 조직이 없으면** 받은 초대가 카드로 보인다. 카드에서 역할 · 접근 권한 · 초대 만료 · 접근 만료를 확인하고 **수락**한다.
  - 관리자 승인이 필요한 초대면 **관리자 승인 대기 중**으로 바뀌고, 승인되면 합류한다.
  - 반려되면 **다시 요청**할 수 있다. 반려 사유와 결정한 사람은 알려 주지 않으니 조직 담당자에게 묻는다.
  - 받은 초대가 없으면 "소속된 조직이 없습니다"가 나온다. 초대 메일의 링크로 참여한다.
  - 초대 메일을 받았는데 초대가 보이지 않으면, 메일을 받은 주소로 로그인했는지 확인한다. 다른 주소라면 **다른 계정으로 로그인**한다.
- **소속 조직이 있으면** 볼 수 있는 첫 메뉴가 열린다.

## 내 계정 — /account

오른쪽 위 이름 메뉴 → **내 계정**.

- 이름과 이메일은 보기만 할 수 있다.
- 비밀번호는 여기서 바꾸지 않는다. 로그아웃한 뒤 로그인 화면의 **비밀번호 찾기 ›**로 바꾼다.
- **회원 탈퇴** → **탈퇴하기** → 확인용 이메일 주소 입력 → **탈퇴**
  - 되돌릴 수 없다. 같은 이메일로 다시 가입해도 새 계정으로 시작하며, 소속과 설정은 복구되지 않는다.
  - 내가 만든 보고서는 조직에 남는다.
  - 내가 조직에 남은 마지막 소유자나 권한 관리자라면 탈퇴할 수 없다. 소유권이나 관리 권한을 다른 멤버에게 넘긴 뒤 탈퇴한다.

## 쓸 수 없는 화면이 나올 때

| 화면 문구 | 뜻 | 할 일 |
|---|---|---|
| "이 기능은 현재 제공되지 않습니다" | 권한 문제가 아니라 계약한 서비스 범위에 없는 기능 | **도입 문의**(sales@laight.ai) |
| "이 화면을 볼 권한이 없습니다" | 내 역할로는 볼 수 없는 화면 | 조직 관리자에게 권한을 요청한다 |
