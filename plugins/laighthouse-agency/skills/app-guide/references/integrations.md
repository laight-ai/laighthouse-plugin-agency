# 외부 연결: 데이터 연동 · MCP · 메신저 알림 (기준일 2026-11-11)

## 데이터 연동 (들어오는 쪽)

라이트하우스로 성과 데이터를 들여오는 방법은 세 가지다.

1. **API 자동 연동** — [데이터 관리] > 매체 API 연동. 매체 계정에 로그인해 권한을 주면 매일 자동 수집된다. 지원 매체는 이 방식을 우선 쓴다.
2. **수동 업로드 (표준 매체)** — [데이터 관리] > 데이터 수동 업로드에서 매체 카드를 골라, 화면의 연결 가이드와 필수 컬럼 양식대로 파일을 올린다.
3. **수동 업로드 (기타 연결)** — 대행사 통합 Rawdata처럼 브랜드 전용 포맷을 쓰는 경우, 라이트에이아이가 브랜드별로 만들어 둔 '기타 연결' 항목에 올린다.

수동 업로드는 **가이드를 반드시 지켜야** 한다. 특히 **필수 데이터 필드(컬럼)가 빠지면 안 되고**, 컬럼 이름·날짜 형식을 바꾸거나 열을 지우면 안 된다.

**예외 상황은 support@laight.ai 로 문의한다.**
- 업로드 화면에 카드가 없는 매체를 운영할 때
- 자체 데이터 포맷(대행사·광고주가 만든 리포트 등)을 쓸 때
- 매체 리포트 양식이 바뀌어 컬럼이 달라졌을 때

파일 준비 규칙, 업로드 순서, 체크리스트, 문의 시 적을 내용은 `references/data-upload.md`에 있다.

## MCP 서비스 — /m/mcp

라이트하우스를 Claude · ChatGPT · Copilot에 연결하는 방법과 Skill 목록을 안내하는 화면.

### Skill이란

라이트하우스가 미리 준비한 명령어. 채팅창에 `/`를 입력해 고르거나 자연어로 요청한다. 브랜드명과 기간만 주면 정해진 절차·형식으로 결과가 나온다. **Skill로 기본 결과물을 받고, 대화로 다듬는 방식**을 권장한다.

### Skill 목록 (화면 기준)

화면에 보이는 Skill 목록과 플러그인 저장소는 **브랜드 유형**에 따라 다르다. 아래는 대표적인 두 가지다.

일반 브랜드

| 묶음 | Skill | 결과 |
|---|---|---|
| 보고서 생성 | /daily-detailed · /daily-summary · /mtd-detailed · /mtd-summary · /monthly-detailed · /monthly-summary · /creative-detailed · /creative-summary | 일간·MTD·월간·소재 보고서. detailed는 실무 상세, summary는 임원용 요약 |
| 외부 요인 (준비 중) | 네이버 검색량 · 뉴스 · 블로그 · 날씨 | 광고 밖 요인 |
| Owned Media 분석 (준비 중) | Facebook · Instagram · YouTube · TikTok 게시글 지표 | |
| 예산 조정 (준비 중) | /ad-spend-optimization · /nextmonth-budget-planning | |

대행사 브랜드

| 묶음 | Skill | 결과 |
|---|---|---|
| 성과 요약 (표, 그래프) | /overall-summary [브랜드] [기간] | 종합 리포트 HTML + 엑셀 |
| | /overall-summary-comment · -total · -tables · -history · -mix | 종합 리포트의 일부만 |
| 보고서 생성 | /daily-report · /weekly-report · /monthly-report · /creative-report | 일간·주간·월간·소재 HTML 보고서 |
| 외부 요인 (준비 중) | 네이버 검색량 · 뉴스 · 블로그 · 날씨 | 광고 밖 요인 |
| Owned Media 분석 (준비 중) | Facebook · Instagram · YouTube · TikTok 게시글 지표 | |
| 예산 조정 (준비 중) | /ad-spend-optimization · /nextmonth-budget-planning | |

사용 예: `/daily-report 브랜드명 26년 7월 20일` 또는 "브랜드명의 26년 7월 20일 기준 일간 보고서를 만들어줘"

설치된 플러그인 버전에 따라 실제로 쓸 수 있는 Skill은 다를 수 있다. Claude에서는 `/` 목록에 보이는 것이 기준이다.

### Claude 연결 방법

A. 플러그인 설치
1. Claude 좌측 사이드바 **사용자 지정** → **플러그인** 탭
2. 우측 상단 **+ 추가** → **마켓플레이스 추가** → **저장소에서 추가**
3. MCP 서비스 화면에 있는 라이트하우스 저장소 URL을 붙여넣고, 자동 동기화를 켠 채 **동기화**
4. 목록에 나타난 **Laighthouse Analytics**를 **추가**

B. 커넥터 연결
1. 플러그인 화면 **커넥터** 탭 → laighthouse 커넥터의 **연결**
2. **계속 연결** (비활성이면 '대상 표시'를 먼저 클릭)
3. 라이트하우스 로그인 (이메일/비밀번호 또는 Google). Google이면 **Approve**로 승인

C. 사용
- 새 대화 입력창 아래에서 **Cowork**를 선택하고 질문한다. 일반 채팅에서도 되지만 Skill이 느리고 토큰을 더 쓴다.

ChatGPT(플러그인), Copilot(MCP 도구)은 MCP 서비스 화면의 **MCP 연결**에서 플랫폼을 바꿔 안내를 본다.

## 메신저 알림 — /m/slack

Slack 또는 Microsoft Teams로 성과 알림을 받는 화면. 탭: **알림 설정** · **연결 관리** · **가이드**.

### 1단계: 메신저 연결

- **Slack**: 가이드 탭의 **Add to Slack**으로 라이트하우스 앱을 워크스페이스에 추가. 버튼이 안 되면 같은 곳의 설치 링크 사용. 설치하면 Slack의 Laighthouse 앱 DM에서 자연어로 성과를 묻고 보고서를 만들 수도 있다 (Slack 사이드바 → 앱 찾아보기 → Laighthouse → 앱 열기).
- **Teams**: Teams 채널에서 워크플로 웹훅 URL을 만들고 **연결 관리** 탭 → **연결 추가**로 등록.

### 2단계: 알림 만들기

알림 설정 탭 → **신규 알림** → 종류 선택. 기존 알림 설정을 불러와 고칠 수도 있다.

**정기 알림** (정해진 주기에 성과 정리)
1. 기본 설정: 알림 이름, 발송 시작일 · 주기(매일 / 매주 평일 / 매주 / 매월) · 시간, 수신처(Slack 채널·DM 또는 Teams 연결)
2. 차트 및 표 설정: 차트(전체 성과 추이 / 매체 단위 비교, Y축 지표 1개, 비교 기준), 표(지표 최대 5개, 비교 기준 → 괄호 안 변화율). 필요 없으면 토글 OFF
3. AI 분석 설정: 분석 지표 1개 + 비교 기준 → **프롬프트 적용** → 미리보기 확인 → 저장
4. 저장한 뒤 **테스트 발송**으로 실제 메시지를 받아 본다.

**이슈 알림** (지표가 크게 변했을 때만)
1. 알림 이름 (예: 메타 CPA 급등 알림)
2. 발송 조건: "특정 [매체 / 캠페인 / 광고그룹]에서, 어제의 [지표]이/가 [비교 기준]과 비교하여 [변동 폭(%)] [상승/하락]" 문장의 빈칸을 고른다. 조건이 감지되면 **다음 날 설정한 시간**에 발송
3. 수신처
4. 예시 확인 → **저장** → **테스트 발송**

수신처 목록이 비어 있으면 1단계 연결을 먼저 해야 한다.
