# 데이터 수동 업로드 상세 가이드

API 자동 연동이 안 되는 매체나 자체 리포트 데이터를 파일로 올릴 때 지키는 규칙. 모든 광고주에게 똑같이 적용된다.

## 1. 연동 방식 고르기

| 상황 | 방식 | 위치 |
|---|---|---|
| API를 지원하는 매체 (Google Ads, Meta Ads, TikTok Ads, Kakao, 네이버 검색 광고, Criteo, Google Analytics, Airbridge, Coupang Wing 등) | **API 자동 연동** (권장) | [데이터 관리] > 매체 API 연동 |
| 네이버 GFA, Toss Place | **담당자 설정** — support@laight.ai 로 문의 | [데이터 관리] > 매체 API 연동 > 해당 카드 |
| API가 없고 업로드 화면에 **매체 카드가 있는 매체** (넷플릭스, 티빙, 타겟픽, 아파트너, 블라인드, 쿠팡 애즈 등) | **수동 업로드** — 매체 카드의 가이드대로 | [데이터 관리] > 데이터 수동 업로드 > 해당 매체 |
| 대행사가 만든 통합 Rawdata, 매체 리포트를 가공한 파일, 카드가 없는 매체(Naver NOSP, CTV, SMR 등) 등 **브랜드 전용 포맷** | **수동 업로드 — '기타 연결'** 항목 | [데이터 관리] > 데이터 수동 업로드 > 기타 연결 > 브랜드 전용 항목 |
| 카드도 기타 연결 항목도 없는 매체, **자체 데이터 포맷**을 처음 쓰는 경우 등 예외 | **support@laight.ai 로 문의** | — |

### '기타 연결'이란

데이터 수동 업로드 화면의 **기타 연결** 묶음(맨 아래 자동 연동 지원 매체 바로 위)에 있는, 브랜드마다 따로 만들어 둔 업로드 항목이다. 이름은 브랜드마다 다르다 (예: "기타(메타)", "기타(네이버GFA)", "Master raw"). 표준 매체 양식이 아닌 데이터(대행사 통합 Rawdata, 원본을 가공한 리포트 등)는 여기에 올린다.

- 항목이 없거나, 새 포맷을 추가해야 하면 직접 만들 수 없다 → **support@laight.ai** 로 데이터 샘플과 함께 요청한다.
- 항목마다 **처음 올린 파일의 컬럼이 이후 양식**이 된다. 그래서 첫 업로드 파일의 구성이 특히 중요하다.

## 2. 업로드 순서

1. https://app.laight.ai 접속 → 좌측 상단 **브랜드 선택**에서 데이터를 올릴 광고주·브랜드(워크스페이스)를 고른다.
2. 좌측 아이콘 바 **[데이터 관리]** → **데이터 수동 업로드**.
3. 올릴 매체 카드를 누른다. 대행사 통합 파일이면 **기타 연결**의 브랜드 전용 항목을 누른다.
4. 창 왼쪽 **연결 가이드**와 아래 **어떤 형태의 파일이어야 하나요**를 확인한다.
5. 아래 **파일 준비 규칙**에 맞게 파일을 정리한다.
6. **파일 올리기** 영역에 끌어다 놓거나 클릭해 선택 → **업로드 완료**.
7. **업로드 이력**에서 상태가 **완료**인지 확인한다. 올린 파일은 **원본 다운로드**로 다시 받을 수 있다.
   - **파일 수정 필요**: 행을 눌러 사유를 보고, 고친 파일 **전체**를 다시 올린다.
   - **문의 필요**: 파일을 고쳐서는 해결되지 않는다. support@laight.ai 로 문의한다.
   - **처리 중**: 페이지를 닫아도 처리는 계속된다.
8. 다음 날 [데이터 관리] > 데이터 수집 현황에서 해당 매체 칸이 '수집됨'으로 바뀌었는지 본다.

업로드 영역에 "업로드 권한이 없습니다. 브랜드 관리자에게 문의하세요."가 보이면 업로드 권한이 없는 것이다. 조직 관리자에게 해당 브랜드 범위의 업로드 권한(예: '데이터 업로드 전용' 역할)을 요청한다.

## 3. 파일 준비 규칙 (필수)

### 형식

- 파일은 **.xlsx 또는 .csv**만 된다. 파일당 최대 50MB, 여러 파일을 한 번에 올릴 수 있다.
- 타겟픽처럼 파일에 날짜 컬럼이 없는 매체는 파일 1개가 하루치다. **데이터 기준일**을 고르고 한 번에 1개씩 올린다.
- 카카오 키워드광고·네이버 비즈어드바이저는 파일명에 든 날짜를 기준일로 쓴다. 내려받은 파일명을 바꾸지 않는다.
- 엑셀 파일에는 **데이터 탭 하나만** 남긴다. 요약·차트·피벗 등 다른 탭은 지운다. (예: 대행사 주간 리포트 파일이면 'Rawdata' 탭만 남김. 넷플릭스 원본은 'Daily data' 탭만 남김)

### 표 모양

- **첫 행은 반드시 컬럼명**이어야 한다. 표 위쪽의 제목·빈 행, 표 왼쪽의 빈 열을 모두 지워 **A1 셀부터 표가 시작**하게 한다.
- **병합된 셀이 없어야** 한다. 병합 헤더(2줄 제목)는 한 줄 컬럼명으로 풀어야 한다.
- **'총계', '합계', '소계' 같이 원본 데이터가 아닌 행은 지운다.** 남아 있으면 그 값이 성과로 더해진다.
- 필터·색칠·서식은 상관없지만, 숨긴 행·열이 있으면 펼쳐서 확인한다.

### 컬럼

- **필수 컬럼이 빠지면 안 된다.** 필요한 컬럼은 업로드 창의 **어떤 형태의 파일이어야 하나요** 표에 나오며, 파일 첫 행이 이 표와 **정확히 일치**해야 한다. **양식 템플릿 내려받기**로 빈 양식을 받을 수 있다.
  - 예) 넷플릭스: Day(YYYY-MM-DD), IO/NAS Line Item ID·Name, Creative ID·Name, Delivered Net Impressions, Clicks, Delivered Amount, Video … Completes 등
- **날짜 컬럼은 반드시 있어야** 하며, 형식은 표에 적힌 대로(보통 **YYYY-MM-DD**) 맞춘다. 한 번 정한 날짜 형식은 계속 같게 유지한다.
- **컬럼 이름을 임의로 바꾸지 않는다.** (예: "노출수" → "Impressions" 금지, 띄어쓰기·괄호·단위 표기까지 그대로)
- **컬럼을 지우지 않는다.** 이번 기간에 값이 없으면 열은 두고 칸을 비우거나 0으로 둔다.
- 컬럼을 새로 추가하거나 빼야 하는 변경(매체 리포트 양식 변경 등)이 생기면, **올리기 전에 support@laight.ai 로 먼저 알린다.** 양식과 다른 파일은 업로드가 실패하거나 일부 값이 반영되지 않는다.
- 광고비 컬럼이 Net인지 Gross인지는 [성과 분석] > 목표 및 수수료 설정 > 고급 설정의 '업로드 데이터 수수료 방식'과 맞춘다. 광고비 컬럼명이 양식과 달라 광고비로 잡히지 않으면 support@laight.ai 로 문의한다.

### 기간

- **정기 업로드는 새 기간의 증분 데이터만** 올린다. 예) 10월 1~14일이 이미 올라가 있으면, 다음에는 10월 15일부터 올린다.
- 이미 올린 기간과 겹치면 **최신 파일로 덮어쓰고**, 그 파일 기간 안에서 **파일에 없는 날짜·행은 비워진다.** 일부 매체·캠페인만 담은 파일로 겹치는 기간을 올리면 나머지 데이터가 사라질 수 있으니 주의한다. 지난 데이터를 고쳐야 할 때만 그 기간 전체를 담은 파일로 다시 올린다.
- **처음 연동할 때는 과거 데이터도 함께, 가능한 한 오래된 시점부터** 올린다. 과거 이력이 길수록 전월·전년 비교, 월간 미디어믹스 학습(약 13개월 이력 사용) 품질이 좋아진다.

### 매체와 메뉴 맞추기

- 각 매체 데이터는 **정해진 매체 카드(또는 기타 연결 항목)에서만** 올린다. 다른 매체 카드에 올리면 매체가 잘못 인식되거나 업로드가 실패한다.
- 엑셀 파일 수동 업로드로 정해진 경우는 **가공하지 않고 그대로** 올린다. 일부 셀이 병합돼 있거나 불필요한 열이 섞인 매체만 위 규칙대로 정리한다.

## 4. 업로드 전 체크리스트

- [ ] 브랜드 선택이 맞다
- [ ] 올바른 매체 카드 / 기타 연결 항목이다
- [ ] .xlsx 또는 .csv, 탭은 1개
- [ ] A1부터 표 시작, 첫 행이 컬럼명
- [ ] 병합 셀 없음, 총계·소계 행 없음
- [ ] 필수 컬럼이 다 있고 이름이 양식과 똑같다
- [ ] 날짜 형식이 양식과 같다 (YYYY-MM-DD)
- [ ] 기간이 이미 올린 데이터와 겹치지 않는다 (덮어쓰기 의도가 아니라면)
- [ ] 첫 연동이면 과거 데이터까지 포함했다

## 5. support@laight.ai 로 문의할 때

다음 경우에는 support@laight.ai 로 문의한다.
- 업로드 화면에 카드가 없는 매체를 운영할 때
- 대행사·광고주 자체 포맷 데이터를 처음 올리려 할 때 ('기타 연결' 항목 생성 필요)
- 매체 리포트 양식이 바뀌어 컬럼 구성이 달라졌을 때
- 업로드 상태가 **문의 필요**일 때, 또는 **파일 수정 필요** 사유대로 고쳐 올려도 계속 같은 결과가 나올 때

메일에 적을 것: 광고주·브랜드명, 매체명, 데이터 샘플 파일(또는 컬럼 목록), 기간, 업로드 주기, 오류 화면 캡처(있으면).
