# 성과 분석 (기준일 2026-11-18)

## 프로모션 캘린더 — /m/calendar

자사·경쟁사 프로모션 일정을 기록하는 달력. 보고서·분석에서 성과 변화의 원인을 볼 때 참고된다.

- 보기: 일 · 주 · 월 · 리스트, **오늘** / 이전 / 다음
- 범례: 자사 · 경쟁사 · 공휴일, **경쟁사 보기** 토글
- **만들기** → **자사 프로모션** 또는 **경쟁사 프로모션**을 골라 일정을 추가한다.

## 목표 및 수수료 설정 — /m/budget

### 월 목표

매월 매체별(필요하면 캠페인별) **예산**과 **목표 지표**를 적는 표. 여기 넣은 값은 보고서·Skill의 목표 달성률, 예산 소진율 계산에 쓰인다.

#### 표 구성

| 열 묶음 | 열 | 설명 |
|---|---|---|
| (행 번호) | 1, 2, 3… | 한 행 = 매체 1개(또는 매체 + 캠페인 1개) |
| 기본 | **매체** | 행마다 **매체 선택**으로 브랜드에 연결된 매체를 고른다 |
| | **캠페인** | 같은 매체를 캠페인 단위로 나눠 목표를 잡을 때 쓴다. 캠페인 예산을 관리할 권한이 있으면 아직 입력하지 않은 달은 캠페인 열이 켜진 채로 열린다. **캠페인 열 추가 / 캠페인 열 삭제**로 켜고 끈다 (권한이 없으면 버튼이 꺼져 있다) |
| 예산 | **Net 예산 (원)** · **수수료** · **Gross 예산 (원)** | 고급 설정의 '목표 입력 수수료 방식'에서 고른 쪽에 입력하면, 다른 쪽은 그 매체·그 달 수수료율로 자동 계산된다 |
| 월 목표 | **목표 지표 열** (예: CPM (원)) | **목표 지표 추가**를 누를 때마다 한 열씩 늘어난다 |
| | **합계** 행 | 예산 합계가 자동으로 나온다 |

#### 목표 지표 추가하기

목표 지표는 **CPM · CPC · CPV · 노출수 · 클릭수 · 조회수 · CTR · VTR 8개** 중에서 고른다. 모든 브랜드에 같은 8개가 나오고, 8개를 모두 추가하면 **목표 지표 추가** 버튼이 꺼진다.

1. 상단에서 달(예: 2026년 11월)을 고른다.
2. **목표 지표 추가**를 누른다 → 표 오른쪽 '월 목표' 묶음에 새 열이 생긴다 (처음엔 목록 첫 지표가 들어감).
3. 열 제목 옆 **∨ (목표 지표 바꾸기)**를 눌러 원하는 지표로 바꾼다.
   - 이미 다른 열에 쓴 지표는 다시 고를 수 없다.
   - 매출·전환수 등 8개 밖의 지표는 이 표에서 목표로 잡을 수 없다. 필요하면 support@laight.ai 로 문의한다.
4. 여러 지표를 잡으려면 2~3을 반복한다 (예: 노출수 목표 + CPM 목표 + VTR 목표).
5. 행마다 매체(와 캠페인)를 고르고 예산·목표값을 입력한다.
6. **저장**. 저장 전이면 **되돌리기**로 마지막 저장 상태로 돌아간다.

입력 요령
- 비용형 지표(CPM, CPC, CPV)는 원 단위, 비율 지표(CTR, VTR)는 % 값으로 적는다.
- 미디어 플랜 엑셀이 있으면 같은 열 순서로 맞춘 뒤 셀을 복사해 표에서 **Ctrl/⌘ V**로 한 번에 붙여넣는다.
- 목표는 **월 단위**다. 다른 달은 상단 달 선택을 바꿔 따로 입력한다.
- 지난달 목표를 그대로 쓸 수 있는 기능은 화면에서 확인되지 않았다 — 엑셀 붙여넣기를 쓰도록 안내한다.

#### 어디에 쓰이나

- 보고서 · Skill의 목표 달성률과 예산 소진율
- 종합 리포트 Mix 계획표의 예산 · CPM · CPC · VTR 초기값
- 목표를 입력하지 않은 지표는 보고서에서 달성률을 계산할 수 없다.

### 수수료

- 연도를 고르고 매체별·월별 수수료율을 입력한다. 목록에 없는 매체는 **매체 추가**.
- **수수료 저장**으로 저장.
- 마크업: Gross = Net × (1 + 수수료율) — 매체에 쓴 금액에 수수료를 더해 청구
- 커미션: Net = Gross × (1 − 수수료율) — 광고주가 낸 금액에서 수수료를 떼고 매체에 집행

### 고급 설정

위치: 목표 및 수수료 설정 화면 맨 아래, '마크업과 커미션' 설명 박스 밑의 **고급 설정**(접힘 상태)을 눌러 펼친다. 설정은 **브랜드별**이다.

#### 수수료 방식

세 항목 모두 **Net / Gross** 중 하나를 누르는 토글이다. 목표를 관리할 권한이 없으면 토글이 꺼져 있다.

| 항목 | 정하는 것 | 영향 받는 곳 |
|---|---|---|
| **출력 수수료 방식** | 광고비를 어떤 기준으로 **보여 줄지** | 보고서, 대시보드, AI 답변(MCP·Slack 포함), 원본 데이터 다운로드 |
| **업로드 데이터 수수료 방식** | [데이터 수동 업로드]로 올린 파일의 광고비가 **Net인지 Gross인지** | 수동 업로드 매체의 광고비 해석 |
| **목표 입력 수수료 방식** | 위쪽 **월 목표** 표에 예산을 **어느 쪽으로 입력할지** | 월 목표 표의 입력 칸 (다른 쪽 금액은 그 달 수수료로 자동 계산) |

동작 원리
- 입력하거나 올린 금액의 기준이 출력 기준과 다르면, **그 매체·그 달의 수수료율**로 바꿔서 보여 준다 (마크업: Gross = Net × (1 + 수수료율), 커미션: Net = Gross × (1 − 수수료율)).
- **CPC, CPM, ROAS** 같은 광고비 기반 지표도 바꾼 광고비로 다시 계산한다. **매출(revenue)은 바뀌지 않는다.**
- 해당 매체·달의 수수료가 "수수료 없음"이면 Net과 Gross가 같게 나온다.

예시: Meta 11월 수수료가 마크업 10%, 출력 수수료 방식이 Gross라면 → Meta에서 100만 원 집행 시 보고서 광고비는 110만 원, ROAS도 110만 원 기준으로 계산된다.

선택 가이드
- 광고주에게 **청구 금액 기준**으로 보고해야 하면 출력 = Gross
- **매체 실집행 금액 기준**으로 봐야 하면 출력 = Net
- 업로드 데이터 방식은 매체 리포트 파일에 적힌 금액이 어느 쪽인지에 맞춘다 (보통 매체 관리자 화면 금액은 Net)
- 목표 입력 방식은 미디어 플랜·견적서에 적힌 예산 기준에 맞춘다

#### 자주 묻는 것

- **보고서 광고비가 매체 화면 금액과 달라요** → 출력 수수료 방식이 Gross이고 해당 매체·월에 수수료가 설정돼 있는지 확인한다.
- **업로드한 매체만 광고비가 이상해요** → 업로드 데이터 수수료 방식이 파일 금액 기준과 맞는지 확인한다. 그래도 광고비가 잡히지 않거나 이상하면 파일의 광고비 컬럼명과 함께 support@laight.ai 로 문의한다.
- **월 목표 표에 Gross 칸만 입력돼요** → 목표 입력 수수료 방식이 Gross로 되어 있는 것이다. Net으로 넣고 싶으면 바꾼다.

## 월간 미디어믹스 — /m/media-mix

제안받을 달의 전월 실적과 그 이전 약 13개월 이력으로 매체별 비용 대비 성과를 학습해, **그 달의 매체별 월 예산 배분**을 제안한다.

1. **대상 기간**(예산을 제안받을 달)을 고른다. 이번 달까지 고를 수 있다. 예: 12월을 고르면 11월 실적을 기준으로 학습한다.
2. **예정 총예산**을 입력한다 (NET 기준, VAT 제외, 원 단위 정수).
3. **비용으로 삼을 지표**(보통 광고비)와 **최적화 대상 지표**(매출, 전환, 클릭 등)를 고른다. 매출 대신 클릭 같은 개수 지표를 고르면 효율을 '성과당 비용'으로 보여 준다.
4. **계산 실행**. 보통 수 분 걸리고, 다른 계산이 돌고 있으면 더 기다린다. 같은 조건으로 진행 중인 내 계산이 있으면 새로 만들지 않고 그 계산을 연다.
5. 아래 **내 실행 기록**(최근 50건)에서 **결과 보기**를 누른다. 대기·계산 중인 계산은 **취소**할 수 있다.

- 고정비 매체는 전월 비용을 그대로 적용한다 (따로 입력하는 칸은 없다).
- 결과 화면: 요약 수치(제안 예산 합계 · 예상 성과 · 예상 효율 · 기준 달 실적 효율)와 매체별 요약 표. 비용은 VAT 제외 Net 기준이다.
- 실행 기록과 결과는 **내가 실행한 계산만** 보인다. 동료가 실행한 결과는 볼 수 없다.
- 계산 실행·취소와 결과 조회는 역할에 따라 권한이 필요하다. 조회 권한만 있으면 실행 폼이 보이지 않는다.
