# 데이터 관리 (기준일 2026-11-18)

## 매체 API 연동 — /m/media

API로 자동 수집하는 매체를 연결하는 화면.

- 상단 필터 탭: 전체 · 광고 매체 · 소셜 채널 및 온드 미디어 · 트래커/MMP · 판매자 어드민 · POS, 그리고 매체 이름 검색창
- 매체 카드 (브랜드에 개통된 매체만 보인다)
  - 광고 매체: Google Ads, Meta Ads, TikTok Ads, Kakao Moment, Kakao 키워드광고, Criteo, 네이버 검색 광고, 네이버 GFA, Coupang Ads(준비 중)
  - 소셜 채널 및 온드 미디어: YouTube Organic, TikTok Organic, 네이버 검색량·뉴스·블로그, Meta Insights(준비 중)
  - 트래커/MMP: Google Analytics, Airbridge
  - 판매자 어드민: Coupang Wing
  - POS: Toss Place
- 카드에 상태가 표시된다: "연결 전" 또는 "연결 N개"
- 하단 **다른 방식으로 연결된 계정**: 파일 업로드·담당자 연동으로 연결했거나 직접 추가한 계정. 여기서 연결 이름을 바꾸거나 해제할 수 있다. 단 직접 추가한 데이터 출처는 해제할 수 없다.

### 연결 방법

매체마다 연결 방식이 다르다.

| 방식 | 매체 | 순서 |
|---|---|---|
| **계정 로그인** | Google Ads, Meta Ads, TikTok Ads, Kakao Moment, Kakao 키워드광고, Criteo, Google Analytics, YouTube Organic, TikTok Organic | 계정 로그인 → 계정 선택 → 완료 |
| **API 키 입력** | 네이버 검색 광고(CUSTOMER_ID·API 키·비밀키), Airbridge(앱 이름·API 토큰), Coupang Wing(업체코드·Access Key·Secret Key) | 키 입력 → 완료 |
| **담당자 설정** | 네이버 GFA, Toss Place | 카드를 누르면 "자동 연동은 당사 담당자가 직접 설정합니다" 안내가 뜬다. support@laight.ai 로 문의한다 |

계정 로그인 예 (Meta Ads)

1. **Meta Ads** 카드를 누르면 연결 창이 열린다.
2. **Meta Ads 로그인 창 열기**를 누르고, 광고 계정 관리 권한이 있는 계정으로 로그인한다.
3. Laight AI가 요청하는 조회 권한을 확인하고 동의한다.
4. 연결할 광고 계정을 선택한다.

매체 연결·해제는 역할에 따라 버튼이 안 보일 수 있다.

## 데이터 수동 업로드 — /m/data-upload

API가 없는 매체의 성과 파일을 올리는 화면.

- 필터 탭: 전체 · 광고 매체 · 판매자 어드민 · 기타 연결
- 화면은 위에서부터 광고 매체 → 판매자 어드민 → 기타 연결 → 자동 연동 지원 매체 순서로 묶여 있다.
- 수동 업로드 매체 예: 네이버 GFA 디스플레이, 네이버 GFA 애드부스트, 쿠팡 애즈, 넷플릭스, 아파트너, 타겟픽, 티빙, 블라인드, 네이버 비즈어드바이저 (브랜드마다 다를 수 있음)
- Naver NOSP, CTV, SMR, CJ YouTube, JTBC YouTube처럼 위 목록에 없는 매체는 표준 카드가 없다. 브랜드 전용 **기타 연결** 항목으로 올린다.
- **기타 연결**: 브랜드 전용으로 만들어 둔 업로드 항목(예: 대행사 통합 Rawdata용 "Master raw", "기타(메타)" 등). 표준 양식이 아닌 데이터는 여기에 올린다.
- 맨 아래 **자동 연동 지원 매체**(Google Ads, Meta Ads, TikTok Ads, Kakao, 네이버 검색 광고 등)도 업로드는 가능하지만, API 연동을 권장하며 수동 업로드는 불가피할 때만 쓴다.

### 매체 카드를 누르면 나오는 창

| 영역 | 내용 |
|---|---|
| 단계 표시 | 1 데이터 수동 업로드 → 2 완료 |
| **연결 가이드** (왼쪽) | 매체 관리자 화면에서 파일을 받는 방법. 모든 카드에 나온다. 넷플릭스·블라인드 등 일부 매체는 화면 캡처와 함께 단계별로 안내하고, 아파트너·타겟픽 등은 공통 4단계(관리자 로그인 → 보고서에서 일자별·캠페인별 보기와 기간 설정 → 엑셀 다운로드(형식·컬럼 변경 없이) → 업로드)로 안내한다 |
| **파일 올리기** | 끌어다 놓기 또는 클릭. .xlsx · .csv, 파일당 최대 50MB, 여러 파일 가능. 단 타겟픽처럼 파일에 날짜 컬럼이 없는 매체는 **데이터 기준일**을 고르고 파일을 1개씩 올린다 |
| **업로드 이력** | 최근 20건. 파일명 · 업로드일(날짜 컬럼이 없는 매체는 기준일) · 상태(처리 중 / 완료 / 파일 수정 필요 / 문의 필요) · 원본 다운로드 |
| **어떤 형태의 파일이어야 하나요** | 필수 컬럼명과 형식 표, **양식 템플릿 내려받기**. 아직 올린 적 없는 항목은 "처음 올리는 파일의 컬럼이 이후 양식이 됩니다"로 나온다 |
| 하단 버튼 | 취소 · 업로드 완료 |

### 업로드 규칙 요약

- 첫 행은 컬럼명, A1부터 시작, 병합 셀·총계 행 없음, 데이터 탭 1개만
- 필수 컬럼 누락·이름 변경·삭제 금지, 날짜 형식 유지
- 정기 업로드는 증분 기간만. 겹치면 최신 파일로 덮어쓰고 파일 기간 안의 빠진 날짜는 비워짐
- 첫 연동 때는 과거 데이터를 최대한 오래전부터
- 업로드 화면에 카드가 없는 매체·자체 포맷 등 예외는 **support@laight.ai**

**자세한 규칙, 체크리스트, 문의 방법은 `references/data-upload.md`를 읽는다.**

## 데이터 수집 현황 — /m/collection-status

매체별로 날짜마다 데이터가 들어왔는지 보는 화면.

- 기간: 30일 · 90일 · 1년. 30일·90일은 1칸 = 1일, 1년은 1칸 = 1주(월–일)
- 색 범례: 수집됨 · 수집됨(이날 데이터 없음) · 미수집 · 오류
- 매체마다 수집 방식(자동 연동 / 파일 업로드)이 표시된다.
- 오른쪽 **수집 알림**: "미업로드"(파일 업로드 매체가 일정 기간 안 올라옴), "수집 지연"(API 매체의 어제 데이터가 아직 안 들어옴) 등을 알려 준다.

보고서 수치가 비어 보이면 가장 먼저 여기서 확인한다.

## 원본 데이터 다운로드 — /m/raw-data

일자·캠페인 단위 원본 데이터를 엑셀로 받는 화면.

### 엑셀 만들기

1. **엑셀파일 생성**을 누른다.
2. 설정기간을 고른다 (최대 31일, 빠른 선택: 어제 · MTD · 지난달 · 지난 30일).
3. 파일명은 비워도 된다 → `{시작}-{종료}_{브랜드}_raw-data.xlsx`
4. **다음** → 확인 후 생성. 목록에서 상태를 보고 내려받는다.

### 열 설정

- **열 설정**에서 엑셀에 넣을 열(분류: 매체·일·캠페인·광고그룹·광고 / 지표: clicks, impressions, spending, revenue, roas, ctr, cpc, cpm, cpa, cvr, 영상 지표 등)을 고르고 끌어서 순서를 바꾼다. 최소 1개, 최대 100개.
- **브랜드 전체에 적용**된다 — 다른 사용자와 자동 생성 파일에도 같은 열이 쓰인다.

### 자동 생성 관리 — /m/raw-data/schedules

- **매일** 또는 **매주** + 시각 + 기간(어제 · 최근 7일 · 이번 달 누적 · 최근 30일)을 골라 **추가**하면 파일이 자동으로 만들어진다.
- 시각은 09:00~19:59(내 기기 시간대)만 고를 수 있다.
