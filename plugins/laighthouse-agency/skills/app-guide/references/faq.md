# 자주 막히는 상황 (기준일 2026-11-18)

**보고서에 어제 데이터가 비어 있어요**
→ [데이터 관리] > 데이터 수집 현황에서 해당 매체 칸을 본다. "수집 지연"이면 API 수집이 아직 안 끝난 것, "미업로드"면 파일 업로드 매체를 아직 안 올린 것. 파일 매체는 데이터 수동 업로드에서 올린다.

**파일을 올렸더니 일부 날짜 데이터가 사라졌어요**
→ 겹치는 기간은 최신 파일로 덮어쓰고, 파일 기간 안에서 파일에 없는 날짜는 비워진다. 빠진 날짜까지 포함한 파일로 다시 올린다.

**업로드 상태가 '파일 수정 필요'예요**
→ 업로드 이력에서 그 행을 눌러 사유를 본다. 흔한 원인: 첫 행이 컬럼명이 아님(위쪽 빈 행·제목), 병합 셀, 필수 컬럼 누락, 컬럼명 변경, 날짜 형식 불일치, 다른 매체 카드에 올림, 탭이 여러 개. 자세한 규칙은 `references/data-upload.md`. 그래도 안 되면 support@laight.ai.

**업로드 상태가 '문의 필요'예요**
→ 파일을 고쳐서 해결되는 문제가 아니다. 파일명과 함께 support@laight.ai 로 문의한다.

**업로드는 '완료'인데 수치가 이상해요 (너무 커요)**
→ '총계'·'소계' 행이 남아 있으면 그 값이 더해진다. 원본에서 합계 행을 지우고 같은 기간으로 다시 올린다.

**업로드할 매체가 목록에 없어요 / 우리 회사 자체 양식이에요**
→ 브랜드 전용 '기타 연결' 항목이 있는지 보고, 없으면 support@laight.ai 로 데이터 샘플과 함께 요청한다.

**매체 리포트 양식이 바뀌었어요**
→ 바뀐 파일을 그냥 올리지 말고 support@laight.ai 로 먼저 알린다.

**목표에 넣고 싶은 지표가 목록에 없어요**
→ 목표 지표는 CPM · CPC · CPV · 노출수 · 클릭수 · 조회수 · CTR · VTR 8개만 고를 수 있다. 매출·전환수 같은 다른 지표의 목표가 필요하면 support@laight.ai 로 문의한다.

**보고서 광고비가 매체 화면 금액과 달라요**
→ [성과 분석] > 목표 및 수수료 설정 > 고급 설정의 '출력 수수료 방식'(Net/Gross)과 매체별 수수료율을 확인한다. 수동 업로드 매체라면 '업로드 데이터 수수료 방식'도 확인한다.

**다른 브랜드 화면으로 가고 싶어요 / 브랜드가 목록에 없어요**
→ 좌측 사이드바 맨 위 브랜드 선택에서 바꾼다. 목록에 없으면 그 브랜드의 열람 권한이 없거나, 데이터가 아직 연결되지 않은 것이다. 조직 관리자에게 확인한다.

**조직 관리 메뉴나 매체 연결 버튼이 안 보여요**
→ 내 역할에 그 권한이 없거나, 계약한 서비스 범위에 없는 메뉴다. 먼저 조직 관리자에게 역할을 확인하고, 화면에 "이 기능은 현재 제공되지 않습니다"가 뜨면 **도입 문의**(sales@laight.ai)를 한다.

**원본 데이터 엑셀 열을 바꿨더니 동료 파일도 바뀌었어요**
→ 열 설정은 브랜드 전체에 적용된다.

**원본 데이터를 31일보다 길게 받고 싶어요**
→ 한 파일은 최대 31일이다. 기간을 나눠 여러 번 만든다.

**Slack 알림 수신처에 채널이 안 나와요**
→ 메신저 알림 > 가이드에서 라이트하우스 Slack 앱을 워크스페이스에 먼저 추가한다. Teams는 연결 관리에서 웹훅을 등록한다.

**Claude에서 라이트하우스 Skill이 안 보여요**
→ [성과 분석] > MCP 서비스의 연결 방법대로 플러그인 설치와 커넥터 연결을 마쳤는지 확인하고, 새 대화에서 Cowork를 선택한 뒤 `/`를 입력한다.

**미디어믹스 계산이 오래 걸려요**
→ 보통 수 분 걸리고, 다른 계산이 실행 중이면 대기한다. 내 실행 기록에서 상태를 본다.
