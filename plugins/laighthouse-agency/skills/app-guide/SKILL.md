# 라이트하우스 화면 안내

사용자가 라이트하우스 웹 앱(https://app.laight.ai)에서 무엇이 어디 있는지, 어떤 순서로 하는지 물을 때 답한다. 데이터를 조회하지 않고, 화면 사용법만 설명한다.

## 참고 파일 고르기

질문에 맞는 파일만 읽는다. 여러 메뉴에 걸친 질문이면 해당 파일을 모두 읽는다.

| 전체 메뉴 구조, 브랜드 전환, 가입·로그인, 처음 시작하기, 내 계정·회원 탈퇴, 쓸 수 없는 화면 | `references/overview.md` |
| 매체 API 연동, 업로드 화면 구성, 수집 현황, 원본 데이터 엑셀 | `references/data-management.md` |
| 파일 업로드 규칙(필수 컬럼, 파일 정리, 기간, 기타 연결, 오류, 문의) | `references/data-upload.md` |

## 답변 원칙

1. **경로부터 말한다.** `좌측 메뉴 [데이터 관리] > 데이터 수동 업로드` 처럼 메뉴 이름을 화면 표기 그대로 굵게 또는 대괄호로 쓴다.
2. **바로가기 링크를 붙인다.** 각 화면 URL은 참고 파일에 있다. 예: https://app.laight.ai/m/budget
3. **단계는 번호 목록으로**, 3~6단계 안에서 끝낸다. 버튼 이름은 화면 표기 그대로 쓴다.
4. **선택한 브랜드 기준이라는 점을 짚는다.** 데이터 관리·성과 분석·소재 운영 화면은 좌측 상단 브랜드 선택에 따라 내용이 바뀐다. 다른 브랜드 얘기라면 먼저 브랜드를 바꾸라고 안내한다.
5. **권한에 따라 안 보일 수 있다고 말한다.** 조직 관리 메뉴와 일부 버튼(매체 연결·해제, 미디어믹스 실행 등)은 역할에 따라 보이지 않는다. 메뉴가 없다는 사용자에게는 조직 관리자에게 권한을 요청하라고 안내한다. 계약한 서비스 범위에 없는 메뉴일 수도 있으니, "이 기능은 현재 제공되지 않습니다"가 뜨면 도입 문의(sales@laight.ai)로 안내한다.
6. **참고 파일에 없는 기능은 지어내지 않는다.** 모르면 "현재 안내 자료에 없는 내용"이라고 말하고 support@laight.ai 로 문의하도록 안내한다.
7. **업로드 질문에는 규칙을 빠뜨리지 않는다.** 위치만 알려 주지 말고, 필수 컬럼 누락·컬럼명 변경 금지, 첫 행 컬럼명·병합 셀·총계 행 제거, 증분 기간만 업로드를 함께 짚는다. 업로드 화면에 카드가 없는 매체나 자체 포맷이면 '기타 연결' 항목을 쓰거나 support@laight.ai 에 문의하도록 안내한다.
8. **목표 질문에는 지표 선택 범위를 알려 준다.** 목표 지표는 CPM · CPC · CPV · 노출수 · 클릭수 · 조회수 · CTR · VTR 8개 중에서만 고를 수 있다. 그 밖의 지표는 support@laight.ai 로 문의하도록 안내한다.
9. **"준비 중" 메뉴는 준비 중이라고 말한다.** (AI 프레젠테이션 등 사이드 메뉴에 '준비 중'이 붙은 메뉴) Skill은 MCP 서비스 화면 표시와 상관없이 `/` 목록에 있으면 쓸 수 있다고 안내한다.
10. 사용자가 데이터 자체(어제 광고비, ROAS 등)를 물으면 이 스킬로 답하지 말고, MCP 도구나 보고서 스킬을 쓴다.

## 답변 예시

질문: 넷플릭스 성과 파일은 어디에 올려?

> **[데이터 관리] > 데이터 수동 업로드**에서 올립니다. → https://app.laight.ai/m/data-upload
> 1. 좌측 상단에서 브랜드가 맞는지 확인합니다.
> 2. 광고 매체 목록에서 **넷플릭스** 카드를 누릅니다.
> 3. 왼쪽 연결 가이드대로 원본 엑셀에서 'Daily data' 탭만 남깁니다.
> 4. 창 아래 **어떤 형태의 파일이어야 하나요**의 필수 컬럼(Day, Delivered Net Impressions, Clicks 등)이 파일 첫 행에 그대로 있는지 확인합니다. 컬럼명을 바꾸거나 지우면 안 됩니다.
> 5. 파일을 끌어다 놓고 **업로드 완료**를 누른 뒤, 업로드 이력에서 상태가 **완료**인지 봅니다.
>
> 지난번에 올린 날짜 이후분만 올리세요. 이미 올린 기간과 겹치면 최신 파일로 덮어쓰고, 파일 기간 안에서 빠진 날짜는 비워집니다.

질문: 우리 대행사 통합 리포트 엑셀을 올리고 싶은데 맞는 매체가 없어.

> 표준 매체 양식이 아닌 자체 포맷은 **[데이터 관리] > 데이터 수동 업로드**의 **기타 연결** 묶음에 있는 브랜드 전용 항목에 올립니다. 목록에 항목이 없다면 직접 만들 수 없으니, 브랜드명·데이터 샘플·업로드 주기를 적어 **support@laight.ai** 로 요청해 주세요. 항목이 생기면 처음 올리는 파일의 컬럼이 이후 양식이 되므로, 첫 파일은 데이터 탭 하나, A1부터 시작, 병합 셀·총계 행 없이 정리해서 올려 주세요.

질문: 월 목표에 VTR 목표도 넣을 수 있어?

> 네. **[성과 분석] > 목표 및 수수료 설정 > 월 목표**에서 **목표 지표 추가**를 누르고, 새 열 제목 옆 ∨를 눌러 VTR을 고르면 됩니다. 목표 지표는 CPM · CPC · CPV · 노출수 · 클릭수 · 조회수 · CTR · VTR 8개 중에서 고를 수 있고, VTR도 여기에 들어 있습니다.
