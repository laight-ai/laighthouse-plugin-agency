# section-2: Executive Summary

신규 MCP 호출 없음. **`assets/prepare.py` 출력의 `digest`**(전체·예산·매체(광고비 비중)·매체-상품의 당월·전월 값과 변화)만
근거로 실행 모델이 직접 쓴다 — 응답 파일을 열어 보지 않는다. 근거 수치가 없는 문장은 쓰지 않는다.

## 빌더 입력

```json
"s2": {"bullets": [
  {"text": "9월 전체 광고비는 <strong>₩2.31억</strong>으로 전월 대비 <strong>+7.2%</strong> 늘었지만 노출은 -0.5%로 비슷했고 ...", "tone": "neutral"},
  {"head": "Google VVC", "text": "는 광고비가 <strong>+36.4%</strong> 늘었지만 조회수는 +12.0% 증가에 그쳐 CPV가 <strong>+21.8%</strong> 상승했습니다.", "tone": "red"}
]}
```

- `head`(선택): 굵게 표시되는 주어. `text`: `<strong>`만 허용. `tone`: `red`/`green`/`yellow`/`neutral`.

## 작성 규칙 (4~5개, 이 순서)

1. **전체** — M0 광고비와 전월 대비 변화율, 노출·조회수 변화율, 매체별 광고비 비중(s4). (`neutral`)
2. **CPV 상승폭 최대 상품** — 광고비·조회수 변화율과 CPV 변화율. (`red`)
3. **CPV 개선폭 최대 상품** — CPV 변화율과 근거. (`green`)
4. **광고비 감소폭 최대 상품** — 광고비·노출 변화와 CPM 변화. (`red` 또는 `yellow`)
5. (선택) **CTR 최고 상품** 또는 광고비 대비 클릭 효율이 두드러진 상품. (`green`)

- 변화율은 digest의 `전월 대비` 값을 그대로 쓴다(소수 1자리, % 지표는 %p). 직접 계산하지 않는다. 금액은 `₩`+콤마(또는 억 단위).
- 상품 차원이 없는 브랜드는 digest에 `매체-상품`이 없다 — 상품 자리에 매체를 쓴다.
