# section-2: Executive Summary

신규 MCP 호출 없음. **`assets/prepare.py` 출력의 `digest`**만 근거로 실행 모델이 직접 쓴다 — 응답 파일을 열어 보지 않는다.
근거 수치가 없는 문장은 쓰지 않는다.

**무엇을 어떻게 쓸지(목적·작성 규칙·예시)는 `guides/executive-summary.md`를 따른다.** 그 파일은 비개발자가 노션에서 고치는
가이드의 사본이다(README의 "요약 가이드" 절). 이 문서는 근거 데이터와 빌더 입력 형식만 정한다.

## 근거 (`digest`)

- `전체`: 당월·전월 값과 `전월 대비`. `예산`: 브랜드 월 예산·소진율.
- `매체`: 당월·전월 값, `전월 대비`, `광고비비중`, 매체 목표가 있으면 `월예산`·`소진율`.
- `매체-캠페인`, `매체-캠페인-광고그룹`: 단위마다 **당월 광고비 상위 + 전월 대비 광고비 변동(절대액) 상위**를 합친 행
  (이름은 `매체 / 캠페인 / …`). 응답에 없는 차원의 단위는 빠진다. `… 생략`은 빠진 행 수다.
- 전월 값이 `-`이면 전월에 집행이 없던 단위(신규)다. 변화율은 digest 값을 그대로 쓴다(소수 1자리, % 지표는 %p).

## 빌더 입력

weekly의 Weekly Summary와 같은 모양이다.

```json
"s2": {"groups": [
  {"title": "소진", "lead": "전 매체에서 안정적으로 소진되었습니다(월 예산 대비 <strong>99.0%</strong>).",
   "media": [{"name": "Meta", "desc": "월 예산 ₩27,500,000 대비 ₩27,380,389를 집행해 99.6% 소진했습니다.", "bullets": []}]},
  {"title": "효율", "lead": "전체 CPV는 ₩11.4로 전월 대비 <strong>-52.7%</strong> 개선되었습니다.",
   "media": [{"name": "Google", "desc": "CPV ₩62.9로 전월 대비 -35.2% 개선되었습니다.",
              "bullets": [{"label": "Skippable(MF2554)", "text": "8월 신규 집행, 광고비 ₩31,425,527 · CPV ₩25.0입니다.", "tone": "green"}]}]}
]}
```

- `media[].name`: digest의 매체 이름 그대로(점 색은 빌더가 붙인다). `bullets[].label`: 캠페인(또는 광고그룹) 이름.
- `tone`: `red`(빨강)/`yellow`(노랑)/`green`(초록)/`neutral`(회색). 본문은 `<strong>`만 허용.
- 예전 형식 `{"bullets": [{"head", "text", "tone"}]}`도 받는다(불릿 목록으로 그린다).
