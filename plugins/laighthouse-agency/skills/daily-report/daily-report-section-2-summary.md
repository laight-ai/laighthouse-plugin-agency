# section-2: Daily Summary

신규 MCP 호출 없음. **`assets/prepare.py` 출력의 `digest`**만 근거로 실행 모델이 직접 쓴다 — 응답 파일을 열어 보지 않는다.
근거 수치가 없는 문장은 쓰지 않는다.

**무엇을 어떻게 쓸지(목적·작성 규칙·예시)는 `guides/daily-summary.md`를 따른다.** 그 파일은 비개발자가 노션에서 고치는
가이드의 사본이다(README의 "요약 가이드" 절). 이 문서는 근거 데이터와 빌더 입력 형식만 정한다.

## 근거 (`digest`)

- `전체`, `매체`: 기준일·전일·전주 동요일 값과 `전일 대비`·`전주 동요일 대비`.
- `매체-캠페인`, `매체-캠페인-광고그룹`, `매체-캠페인-광고그룹-광고`: 단위마다 **기준일 광고비 상위 + 전일 대비 광고비 변동(절대액)
  상위**를 합친 행(이름은 `매체 / 캠페인 / …`). 응답에 없는 차원의 단위는 빠진다. `… 생략`은 빠진 행 수다.
- 값이 `-`이면 그날 집행이 없었다는 뜻이다(전일 `-` = 신규 집행, 기준일 `-` = 집행 중단).
- 변화율은 digest 값을 그대로 쓴다(소수 1자리, % 지표는 %p). 직접 계산하지 않는다.

## 빌더 입력

```json
"s2": {"bullets": [
  {"head": "전체", "text": "광고비 <strong>₩7,305,121</strong>로 전일 대비 +0.9%, 조회수 792,573회(+3.7%), CPV ₩9.2입니다.", "tone": "neutral"},
  {"head": "Google Non-skip(MF2554)", "text": "광고비가 ₩412,000에서 ₩1,103,500으로 <strong>+167.8%</strong> 급등했습니다. 예산·입찰 변경 여부를 확인해 주세요.", "tone": "red"}
]}
```

- `head`: 굵게 표시되는 주어. `text`: 본문 — `<strong>`만 허용, 다른 태그는 글자로 보인다.
- `tone`: 점 색 — `red`(빨강), `green`(초록), `yellow`(노랑), `neutral`(회색). 가이드의 색 이름을 이 값으로 옮긴다.
