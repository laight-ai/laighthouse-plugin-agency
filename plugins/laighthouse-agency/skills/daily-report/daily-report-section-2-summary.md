# section-2: Daily Summary

신규 MCP 호출 없음. **`assets/prepare.py` 출력의 `digest`**(전체·매체·매체-상품의 기준일·전일·전주 동요일 값과 변화)만 근거로
실행 모델이 직접 쓴다 — 응답 파일을 열어 보지 않는다. 근거 수치가 없는 문장은 쓰지 않는다.

## 빌더 입력

```json
"s2": {"bullets": [
  {"head": "전체", "text": "광고비 <strong>₩7,305,121</strong>로 전일 대비 +0.9%, 조회수 792,573회(+3.7%), CPV ₩9.2입니다.", "tone": "neutral"},
  {"head": "Meta Reach", "text": "CPV가 ₩10.5에서 ₩12.9로 <strong>+22.2%</strong> 올라 상품 중 상승폭이 가장 큽니다.", "tone": "red"}
]}
```

- `head`: 굵게 표시되는 주어(`전체` 또는 `{매체} {상품}`). `text`: 본문 — `<strong>`만 허용, 다른 태그는 글자로 보인다.
- `tone`: 점 색 — `red`(악화·점검), `green`(개선), `yellow`(주의), `neutral`(관찰).

## 작성 규칙 (3~5개, 이 순서)

1. **전체** — D0 광고비와 전일 대비 변화율, 조회수와 변화율, CPV. (`neutral`)
2. **CPV 상승폭 최대 상품** — 전일 CPV → D0 CPV, 변화율, 같은 상품의 광고비·조회수 변화. (`red`)
3. **CPM 상승폭 최대 상품** — 2번과 다른 상품일 때만. 전일 → D0 CPM, 노출 변화. (`red`)
4. **CPV 개선폭 최대 상품** — D0 CPV와 개선율. (`green`)
5. (선택) 그 밖에 광고비·노출이 전일 대비 ±20% 이상 움직인 상품 하나. (`yellow`)

- 변화율은 digest의 `전일 대비`·`전주 동요일 대비` 값을 그대로 쓴다(소수 1자리, CTR 등 % 지표는 %p). 직접 계산하지 않는다.
- 상품 차원이 없는 브랜드는 digest에 `매체-상품`이 없다 — 상품 자리에 매체를 쓴다.
- 금액은 `₩` + 천 단위 콤마(100 미만은 소수 1자리), 횟수는 콤마.
- 상품별 예산이 아직 없으므로 **예산 페이싱(과속/저소진) 문장은 쓰지 않는다.**
