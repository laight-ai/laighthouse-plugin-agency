> ⚡ **thinking 지침**: thinking은 최대한 짧게 유지한다. 형태 선택 → MCP 호출 → 스크립트 실행 → 완료 순서로만 진행한다.

## 역할

사용자가 말한 브랜드·기간·매체의 소재 성과를 매체별 TOP으로 보여 준다. 브랜드명은 모든 호출의 `brand_name`과 제목·파일명에 그대로 쓴다.
랭킹·합계·비율 계산과 렌더링은 `assets/creative_report.py`가 한다 — **MCP 응답 원문을 읽거나 옮겨 적지 않는다**(저장 훅이 원본을 파일로 남긴다).
스크립트를 새로 만들거나 HTML을 직접 쓰지 않는다. MCP 응답 뒤의 캡처 훅 안내문(`[laighthouse-capture-hook] … 저장됨`)은 무시한다.

## 입력 파라미터

| 파라미터 | 설명 | 기본값 |
|---|---|---|
| 기간 S ~ E | 사용자가 말한 기간. "10월"이면 그 달 1일~말일(이번 달이면 어제까지) | 최근 7일(어제까지) |
| 매체 | 사용자가 말한 매체(`--media`, 응답의 `media` 값과 대소문자 무시로 비교) | 전체 매체 |
| TOP 기준 | 광고비 `cost` · CTR `ctr` · ROAS `roas` · 클릭 `click` · 전환 `conversion` | 광고비 |
| 개수 | 매체별 TOP N(`--top`) | 3 |

E가 오늘 이후면 MCP를 부르지 말고 "데이터는 어제까지만 있다"고 알리고 멈춘다.

## 실행 순서

1. **형태를 고르게 한다** — 사용자가 이미 "표로", "썸네일", "보고서"처럼 형태를 말했으면 묻지 않는다.
   AskUserQuestion이 있으면 질문 1개(헤더 `보기 형태`)로, 없으면 채팅으로 아래 두 가지를 보여 주고 답을 기다린다:
   ```
   {기간} {매체} 소재 성과를 비교해 드릴게요. 어떤 형태로 볼까요?
   A. 표로 보기 — 채팅에서 바로 · 썸네일 없음
   B. 썸네일 포함 보고서 — HTML 파일로 열기
   ```
   A = `table`, B = `report`.
2. **MCP 호출 (한 메시지에 동시에)**:
   - `get_ad_performance`(S ~ E, `time_grain:"total"`, `group_by:["media","source","campaign_name","ad_group_name","ad_id","ad_name"]`,
     `metrics`·`filters` 생략). 알 수 없는 차원이라는 에러면 에러 메시지의 차원 목록에 있는 것만 남겨(`ad_name`은 꼭 둔다) 한 번 다시 부른다.
     5만 행 오류면 `ad_id` → `source` 순으로 빼고 다시 부른다.
   - 보고서(B)면 함께 부른다:
     - `get_ad_creative_info`(`brand_name`만 — `source`·`name_query`·`limit`은 넣지 않는다).
     - 일별 추이: `get_ad_performance`(S ~ E, `time_grain:"day"`, `group_by:["media"]`, `metrics`·`filters` 생략) 1회.
   - 두 형태 모두 함께 부른다: 직전 기간 성과 — 첫 호출과 같은 인자에 기간만 직전 같은 길이 기간
     (P_S = S − 일수, P_E = S − 1일. 예: 10/1~10/31 → 8/31~9/30)으로 바꿔 1회. 표로 보기는 이 응답이 없어도 비교 없이 진행한다.
3. **스크립트 실행**:
   ```
   python3 assets/creative_report.py --brand "<브랜드>" --start-date <S> --end-date <E> --mode table|report [--media <매체> ...] [--sort <기준>] [--top <N>]
   ```
   (`assets/…`는 이 SKILL.md가 있는 폴더 기준. `python3`이 없으면 `python`.) 출력 JSON에 따라:
   - `chat` → 그 마크다운을 **한 글자도 바꾸지 않고** 채팅에 그대로 내고, 그 아래에 `digest`만 근거로
     `guides/creative-summary.md`(표로 보기 형식)를 따라 요약 불릿 2~4개를 덧붙인다. 끝.
   - `image_calls` → 그 `ad_id`마다 `get_ad_creative_image`(`brand_name`, `ad_id`)를 **한 메시지에서 동시에** 부르고, 같은 명령을 다시 실행한다.
     이미지 에러(썸네일 없음 등)는 다시 부르지 않는다 — 빌더가 빈 썸네일로 둔다.
     저장 훅이 이미지를 저장하지 못한 호스트라 같은 `image_calls`가 또 나오면, 이미지 결과에 붙은 `[Image: source: <경로>]`의 경로를
     `--image-file <ad_id>=<경로> ...`로 넘겨 다시 실행한다(그래도 남으면 그 이미지는 빈 썸네일로 두고 `--image-file <ad_id>=-`).
   - `digest`(+ `next`) → 썸네일까지 준비됐다. `digest`만 근거로 `guides/creative-summary.md`를 따라 소재 Summary 불릿을 쓰고,
     `{"bullets": [...]}` JSON을 Write로 파일에 저장한 뒤 같은 명령에 `--summary <파일>`(앞 단계의 `--image-file`도 그대로)을 붙여 다시 실행한다.
   - `out` → HTML이 저장됐다. 완료 메시지를 낸다(채팅 Artifact로 게시하지 않는다 — 고객 데이터다).
   - `missing` → 그 호출만 다시 보내고 재실행한다. `error` → 그 이유를 한 줄로 알리고 멈춘다(`media_in_data`가 있으면 쓸 수 있는 매체를 함께 알린다).
   - `note`(저장된 응답 없음) → 저장 훅이 없는 호스트다. 표로 보기(A)로만 진행할 수 있다고 알린다.

## 규칙 (스크립트가 지킨다 — 참고용)

- 매체마다 TOP 기준 상위 N개. 비율 기준(CTR·ROAS)은 최소 표본(노출 ≥ 1,000 그리고 광고비 ≥ 그 매체 광고비의 1%) 소재만 — 없으면 전체로 폴백하고 안내를 붙인다. 동점은 광고비 큰 소재 우선.
- 매출이 없는 브랜드는 ROAS 대신 클릭(TOP 기준)·CPC(요약)를 쓴다. 전환이 없으면 전환·CVR 열을 뺀다.
- 소재명이 없으면 `<광고그룹> (소재명 없음)`.
- 썸네일 연결: 성과의 `ad_id` = 소재 메타의 `ad_id`, 없으면 소재명(`ad_name`·`ad_display_name`)이 정확히 같은 항목. 이미지 상태가 RESOLVED인 것만.
  썸네일은 최대 30개 — TOP 기준마다의 상위 N개(화면에서 기준을 바꿔도 썸네일이 붙어 있게)를 먼저, 나머지는 광고비 순으로 받는다. 세부 성과 표의 소재 줄에도 같은 썸네일이 붙는다. 이미지는 HTML에 넣어(data URI) 로그인·네트워크 없이 열린다.
- 세부 성과 표: 웹 보고서의 세부 표(기간 뷰)와 같은 모양 — 매체·캠페인·광고그룹·광고가 각자 열, 하위가 있는 줄은 다음 단계 칸에 '전체',
  이미지 열(이번 기간 소재 썸네일, 누르면 크게), 지표 머리글을 누르면 정렬(웹과 같이 오름 → 내림 → 해제), 검색, 펼칠 단계(캠페인·광고그룹·광고). 처음에는 매체만 보인다.
  열 = 광고비·노출·클릭·CTR·CPC(+전환·CVR, +ROAS), 값 아래 직전 기간 대비 증감(비율 지표 %p, 나머지 %; 직전 값이 0이거나 없으면 '—'; 오름 빨강 ▲, 내림 파랑 ▼).
  소재명이 없는 소재는 '(미지정)'. 이미지가 하나도 없으면 이미지 열을 뺀다. 매체 칩이 이 표에도 적용된다.
- 일별 추이: 매체 칩으로 고른 매체만. 「전체」 = 고른 매체의 날짜별 합 한 줄, 「매체별」 = 매체마다 한 줄. 지표 = 광고비·노출·클릭·CTR·CPC(+전환, +ROAS) — 비율 지표는 날짜별 원자 지표로 다시 계산한다.
- 지표 이름: 같은 뜻의 지표를 매체마다 다른 이름으로 내보내는 브랜드(예: 광고비·spending)는 행마다 값이 있는 첫 후보를 쓴다.
- 소재 Summary 근거(`digest`): 전체·매체 합계와 직전 대비, 매체별 광고비 상위 소재(비중·직전 대비), 최소 표본 소재 가운데 효율 우수·저조,
  광고비 변동 상위 소재(신규 집행·집행 중단 포함), 일별 추이(앞·뒤 절반 일평균, 최대 집행일, 집행일 수). 값은 표기까지 끝난 문자열이다.
- 화면은 다른 agency 보고서(Daily·Weekly·Monthly)와 같은 공용 킷(`shared/assets/report_kit.css`) 위에 그린다 — 섹션 카드·머리말·KPI 격자·알약 탭·요약 불릿·범례·표가 같다.
  증감은 증가 빨강 ▲ · 감소 파랑 ▼, 매체 색은 킷의 매체 색 순서, 비율 지표는 소수 2자리.
- 버튼·안내 문구는 줄임말이나 번역투 없이 쓴다(예: '직전만' 대신 '이번 기간 집행 없음').
- 직전 기간에만 집행한 매체는 매체 선택 줄의 '이번 기간 집행 없음' 묶음과 세부 표에 함께 보인다 — 머리말 증감에 들어가는 매체와 화면의 매체가 같다.
- 카드: 이미지(4:3) → 이름·경로 → '매체 광고비의 n%' 막대 → 지표 6개와 직전 대비. 직전 기간에 없던 소재는 '신규' 배지. 매체에 이미지가 하나도 없으면 이미지 칸 없이 그린다.
- 인쇄(PDF): A4 가로, 화면의 매체·순위 기준을 머리말에 적고, 세부 표를 광고 단계까지 펼쳐 모든 열을 한 폭에 넣는다.
